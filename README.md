# 🎯 Jogo de Adivinhar Números em Python

## 📌 Sobre o projeto

Este projeto é um jogo simples desenvolvido em Python durante um curso de programação. O objetivo é fazer com que o jogador tente adivinhar um número escolhido aleatoriamente pelo programa.

O projeto foi criado para praticar conceitos básicos da linguagem Python e desenvolver a lógica de programação por meio de uma atividade interativa.

## 🎯 Objetivos

* Praticar lógica de programação.
* Trabalhar com variáveis e tipos de dados.
* Utilizar estruturas condicionais e de repetição.
* Aprender a gerar números aleatórios.
* Desenvolver um projeto prático durante o curso.

## ⚙️ Tecnologias e ferramentas utilizadas

* **Linguagem:** Python
* **Editor de código:** Visual Studio Code (VS Code)
* **Biblioteca:** `random`

## 🎮 Como funciona

O programa sorteia um número aleatório dentro de um intervalo definido no código. O jogador deve tentar descobrir qual número foi escolhido.

A cada tentativa, o programa verifica o palpite e informa se o jogador precisa tentar um número maior ou menor, conforme a lógica implementada.

O objetivo é acertar o número sorteado.

## ▶️ Como executar

1. Instale o Python no computador.
2. Abra o projeto no Visual Studio Code.
3. Abra o terminal integrado.
4. Execute o arquivo Python:

```bash
python adivinhar_numeros.py
```

**Observação:** substitua `adivinhar_numeros.py` pelo nome real do seu arquivo, caso seja diferente.
